# Dashboard walkthrough

The [screen recording](screenshots/walkthrough.mp4) follows the three persona views of the running November 2026 release. The [supervisor](screenshots/supervisor.png) station board surfaces congestion and missing instrumentation. The [plant manager](screenshots/manager.png) view connects production trends to individual stations. The [leadership](screenshots/leadership.png) view presents assumption-driven business scenarios. These are actual browser captures from the regenerated 2,000-finished-vehicle mixed simulation. For a live walkthrough, start the local API and Vite using the [quick start](../README.md), open the station board, inspect S17, and then switch between Plant Manager and Leadership. ROI projections depend on the configured assumptions.
